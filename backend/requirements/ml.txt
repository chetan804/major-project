# Installed where forecasting, anomaly detection, waste classification and
# environmental analytics run (API process for on-demand inference, and the
# worker process for training/evaluation jobs).
#
# NOTE ON DEEP LEARNING: PyTorch is intentionally NOT a hard dependency.

# implemented behind the optional extra in `vision.txt`, to be enabled when a
# real labelled image corpus and GPU/CPU budget are available. Fabricating
# deep-learning accuracy on a synthetic corpus would violate the project's
# scientific-integrity rules (sections 49, 62, 64).
